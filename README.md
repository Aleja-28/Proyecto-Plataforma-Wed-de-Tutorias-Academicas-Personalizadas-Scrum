# Plataforma Web de Tutorías Académicas Personalizadas

Sistema web desarrollado para la gestión, registro de estudiantes y administración de materias y tutorías académicas con persistencia en tiempo real en la nube.

---

## Enlace en Producción
La aplicación se encuentra desplegada y accesible en la nube a través de Vercel:
* **URL de la aplicación:** [https://proyecto-plataforma-wed-de-tutorias.vercel.app](https://proyecto-plataforma-wed-de-tutorias.vercel.app)

---

## Tecnologías y Stack Utilizado
* **Frontend:** React / TypeScript / Vite (Interfaz rápida y moderna).
* **Estilos:** CSS / Componentes personalizados.
* **Base de Datos y Backend as a Service (BaaS):** Supabase (PostgreSQL para almacenamiento en la nube de perfiles y materias).
* **Despliegue y Hosting:** Vercel.

---

## Esquema de la Base de Datos (Supabase)
La aplicación se conecta a dos tablas principales alojadas en Supabase:
1. **`profiles`**: Almacena la información de los estudiantes registrados (ID, nombre completo, correo institucional/personal, institución, carrera y semestre).
2. **`subjects`**: Administra el catálogo de materias disponibles para las tutorías.
